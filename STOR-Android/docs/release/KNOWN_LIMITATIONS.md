- 实测设备仅 realme RMX5200 / Android 16；工程声明 Android 9+ ARM64，不等于所有系统和厂商均已验证。
- 当前设备为 4 KB 页。原生库 ELF 与 APK 对齐可做静态检查，真实 16 KB 页设备尚未验证。
- 复杂游戏背景、小字、艺术字和竖排文字没有完成分层准确率验收；未加入方向分类与文档矫正。
- 系统禁止截图的页面、隐藏浮层的页面可能无法使用；屏幕捕获由系统和目标应用限制。
- 尚未覆盖多厂商后台策略、30 分钟连续操作、耗电温升、最大字号和所有主题组合。
- 真实服务验证过正常完成与立即取消；已收到部分译文后取消、运行中编辑／切换语言和异常网络等完整真机组合未逐项覆盖。
- 项目专用证书与此前 Debug 证书不同，不能直接覆盖旧 Debug 安装。internal.1（code 3）到 internal.2（code 4）已在本机同证书覆盖更新并保留配置。
