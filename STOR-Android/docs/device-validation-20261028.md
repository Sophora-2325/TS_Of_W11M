# 单机真机验证记录

日期：2026-10-28。设备：realme RMX5200；Android 16 / API 36；ARM64；1440×3136；4 KB 系统页。内部 debug 原型，未调用翻译服务。

版本范围：本记录为 P0–P2 `0.1.0-poc`。后续 `0.2.0-dev` 翻译功能代码另见 [P3 记录](p3-delivery-20261028.md)，尚未安装或真机测试。

## 已执行

- 主 APK 和设备测试 APK 安装成功，真实 Android ONNX / OpenCV OCR 测试 `OK (1 test)`。
- 初次模型加载 267 ms；中英日三张固定样本分别 204 / 114 / 114 ms，均与桌面参考文字一致。
- 后续同算法复测加载 197 ms，三图 140 / 99 / 107 ms。这些是单次样本观测，不是 p95、冷启动统计或发布性能结论。
- 悬浮窗授权、屏幕捕获同意、后台浮键、矩形框选、同图调整、取消、重新截图、原文编辑、键盘显示、复制并粘回本次合成文字。
- 较早版本在横屏中文截图中得到完整文字，观测识别 188 ms。
- 应用内结束会话后，系统 MediaProjection 输出为 `null`；重新开启时正常再次请求同意。

## 本轮发现并修改

1. **旋转后浮键位置偏到屏幕中间**：改为保留吸附的左/右侧，每次显示按当前屏幕重新定位。实际观察到横屏右侧贴边，以及从左侧旋转回竖屏后仍贴左边；证据在 `docking-portrait-fixed.txt` / `docked-landscape-fixed.png`。
2. **浮键进入冻结截图，遮挡文字**：最终采用连续连接原 VirtualDisplay / Surface，同步移除浮层，按单调时钟时间戳过滤移除前已排队的帧。修正版在浮键覆盖文字的位置连续切换英文、中文、日文，完整识别均与样本一致，耗时 220 / 156 / 151 ms，见 `timestamp-frame-regression.json`。

曾尝试按次断开再连接 Surface；测试中出现空白帧和取帧不稳定，已撤回，未保留此实现。失败证据保留用于追溯，不能将 `clean-frame-regression.json` 的失败轮次算作通过。

## 已知限制和未完成项

- 该机当前字体/显示设置下，系统屏幕捕获确认框在横屏中裁掉底部按钮；竖屏授权后使用横屏可继续。记录为该设备/系统组合限制，未扩展到其他机型。
- 最终时间戳版本的额外横屏回归被取消；旧版本横屏通过不能直接算成最终版本横屏复测通过。
- 没有进行锁屏、系统停止投屏入口、多厂商、150 张真实样本、连续 50 次、长期待命、温升/耗电及 release 性能测试。
- 未接入联网翻译、服务配置与 Key 保存。
- 这是单机原型证据，P1/P2 的完整兼容和准确率验收尚未全部满足。

## 收尾

用户要求停止重复测试后，未再追加测试；通过应用按钮结束投屏，并恢复此前记录的旋转模式 `lock 1`。修正版已安装在手机上。
