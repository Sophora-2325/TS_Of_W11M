# STOR Android 界面风格优化方案

日期：2026-10-29。范围：功能开启页、翻译设置、翻译结果浮层。依据本次用户提供的三张手机截图；本轮仅提供设计方案与高保真预览，没有修改 Android 功能代码、打包或操作手机。

## 推荐方向：石墨灰 × 鼠尾草绿

保留现有绿色品牌识别度，用中性深色承载阅读内容，用低饱和绿色标记主要操作。三页统一字体、间距、圆角、图标和状态表达。

截图中主要可见问题：

- 开启页的介绍、旧会话状态和操作步骤同时占据较多高度，主操作被分散。
- 深绿色页面、紫灰色状态卡和系统灰色按钮缺少统一的色彩关系。
- 截图的衬线字形较强，标题、正文和辅助文字的字重层级不够清楚。字体可能受到手机系统字体设置影响，单凭截图不能确认来源。
- 翻译浮层对短文本仍占据很大空间；多个灰色按钮权重相近，译文和下一步操作不够突出。

这些是当前截图的视觉观察，不能据此断言所有字号、横竖屏或辅助功能都存在同样问题。

## 三页调整

| 页面 | 布局与内容 | 主要操作 |
|---|---|---|
| 功能开启页 | 顶栏保留 STOR 和设置；品牌文案缩为两行，说明缩为一句。用小型日文→中文示例解释用途；状态与按钮靠近，三步说明紧凑排列，隐私说明放底部。 | 未开启时突出“开始屏幕翻译”；开启后同位置显示“结束屏幕会话”，状态同时用文字说明。 |
| 翻译设置 | 顶栏统一返回和标题；服务地址、模型、Key 使用同一输入框样式。地址规则按需查看；Key 说明缩为一句。语言选择使用同一分段控件，保存按钮固定在底部。 | 保留显式“保存设置”和保存成功反馈；不增加自动连接测试、自动保存或自动重试。 |
| 翻译浮层 | 用不透明、紧凑的浮层保留目标应用上下文。短文本按内容收紧；原文小于译文但仍可编辑。复制原文放在原文栏附近；调选区、重截图降为次级操作。 | 翻译前主按钮为“翻译”；完成后突出“复制译文”；语言与设置保持可达；关闭始终可见。 |

预览中的底层阅读页面仅为虚构示例，不是新增阅读器功能。开启页的日文/中文也是明确标注的静态示例，不代表自动翻译。服务地址和模型名沿用截图中的显示内容，仅用于排版；没有查询服务、读取真实 Key 或发送请求。

## 视觉规范

| 项目 | 建议 |
|---|---|
| 页面背景 | `#121614`，中性偏绿的石墨色 |
| 浮层/输入表面 | `#1D2420` |
| 主要操作 | `#B9CBA9`，按钮文字 `#19251B` |
| 主要/次级文字 | `#F2F5EF` / `#A9B4AB` |
| 分隔线 | `#354238`，仅用于建立分组，不给每段内容加卡片 |
| 排版 | 无衬线；主标题约 28–30sp，页面标题 19–22sp，正文 15–16sp，辅助说明 12–13sp |
| 间距 | 页面左右 24dp，常规 8dp 网格；主按钮高 56dp；主要图标操作区目标为至少 48dp |
| 圆角 | 输入框 12dp，主按钮 16dp，结果浮层约 22–24dp |
| 图标 | 单一线性图标风格；图标按钮必须有可访问名称，重要操作不只依靠图标或颜色 |

预览采用 Noto Sans SC 字体与 Lucide 图标，均为本地资产，没有依赖在线字体服务。字体为浏览器示意资产，未加入 Android APK。落地时先确认系统字体影响，继续尊重系统字号缩放；不默认把整套预览字库打进安装包。

## 翻译浮层状态

| 状态 | 显示与动作 |
|---|---|
| 尚未翻译 | 显示原文与一句发送提示；“翻译”为主按钮，暂不显示无内容可复制的大按钮。 |
| 正在翻译 | 显示已有译文和运行状态，提供清楚的“取消”；不重复发送请求。 |
| 翻译完成 | 译文更大、更易读，“复制译文”为主按钮；再次翻译为次级操作，保留现有缓存语义。 |
| 失败或取消 | 保留原文和已有部分译文，显示具体提示与手动重试入口。 |
| 修改原文或切换语言 | 继续沿用现有取消旧请求、清空旧译文、手动触发翻译的行为。 |

短文本浮层不再默认填满屏幕；长文本设置高度上限并让内容滚动，头部、关闭与底部操作保持可达。键盘弹出时优先让编辑区和必要操作可见。预览显示的是默认字号下的短文本方案，不是最终长文本和横屏验收。

## 如确认实施，分三步落地

1. **统一视觉基础**：整理 Compose 与原生浮层共用的色彩、排版和控件尺寸。把深色主题默认落到紫灰色的区域明确覆盖为设计色；不调整权限、捕获和翻译状态机。
2. **优先改结果浮层**：在 `OverlayController.kt` 调整短文本高度、原文/译文层级、操作布局及状态主次。保留复制、原文编辑、语言、设置、调选区、重截图、取消和重试。
3. **整理开启页与设置**：修改 `MainActivity.kt`、`TranslationSettingsScreen.kt` 的布局、文案和样式；只做一次变更相关的真机检查。

验收关注：默认及放大字号不裁切、键盘不遮挡关键按钮、横屏短文本可操作、长文本可滚动；已有功能入口完整、未点击翻译不请求、保存和取消行为保持一致。当前预览没有完成这些 Android 真机适配验证，不据此宣称完整无障碍达标。
